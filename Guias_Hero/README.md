# Guias de proporcao do Hero

Arquivos criados para orientar a troca das imagens de fundo da primeira dobra.

- `hero-desktop-1920x1080.svg`: desktop padrao, proporcao 16:9.
- `hero-ultrawide-3440x1440.svg`: telas largas, proporcao aproximada 21:9.
- `hero-tablet-horizontal-1536x1008.svg`: tablet em paisagem, proporcao aproximada 3:2.
- `hero-tablet-vertical-1008x1536.svg`: tablet em retrato, proporcao aproximada 2:3.
- `hero-mobile-1080x1920.svg`: mobile, proporcao 9:16.

Use as areas azuis para preservar legibilidade do texto e as areas douradas para posicionar o foco visual principal.
As faixas vermelhas indicam margem de corte provavel por causa do `background-size: cover`.
